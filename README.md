# Student Grade Calculator Using Python

## About the Project
This project calculates student grades based on their marks using Python conditional statements.

## Objective
To practice if, elif, and else statements and apply them to a simple data analysis problem.

## Tools Used
- Python
- Jupyter Notebook

## Grading Criteria
| Marks Range | Grade |
|---|---|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| 0–49 | F |
| Below 0 or above 100 | Invalid Marks |

## Features
- Automatically calculates student grades.
- Uses a manually created student dataset.
- Displays student names, marks, and grades.
- Handles invalid marks.

## Learning Outcomes
- Understanding conditional statements.
- Using Python functions and dictionaries.
- Processing data using loops.
- Testing different grading conditions.

## Conclusion
This project demonstrates how Python can automate student grade calculation using predefined grading rules.
